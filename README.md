# AI-Powered Email Threat Detection & Forensic Intelligence Platform

## Overview

An AI-powered platform for detecting phishing, spoofing,
impersonation and fraudulent emails.

## Features

- Email threat detection
- Email header forensics
- SPF/DKIM/DMARC analysis
- IOC extraction
- Domain similarity detection
- DNS analysis
- IP geolocation
- Threat scoring
- Graph-based infrastructure analysis
- Forensic report generation

## Technologies

- Python
- Streamlit
- Machine Learning
- NLP
- NetworkX
- Plotly
- DNS
- ReportLab
